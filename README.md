# VideoScribe — транскрибация видео и аудио

Десктоп-программа для Windows в духе TurboScribe: вставляете ссылку на YouTube
(или другой сайт) либо открываете локальный видео/аудиофайл — получаете точный
текст с таймкодами, спикерами и экспортом в TXT, SRT, VTT, DOCX, PDF.

## Установка (готовая программа, Python не нужен)

1. Откройте страницу релизов:
   **<https://github.com/sashapas87-tech/videoscribe/releases/latest>**
2. Скачайте **`VideoScribe-Setup.exe`** и запустите. Если SmartScreen покажет
   предупреждение (программа не подписана сертификатом) — нажмите
   **«Подробнее» → «Выполнить в любом случае»**.
3. Установщик создаст ярлыки в меню Пуск и на рабочем столе. Установка идёт
   в профиль пользователя — права администратора не нужны.

Портативный вариант без установки: скачайте `VideoScribe-Portable-Windows.zip`,
распакуйте и запустите `VideoScribe\VideoScribe.exe`.

Требования: Windows 10/11 (64-бит). Интернет нужен для скачивания видео по
ссылкам и при первом использовании выбранной модели Whisper (модель скачивается
один раз, дальше распознавание работает офлайн).

> ⚠ В exe-версии недоступно определение спикеров (диаризация) — пакет torch
> слишком тяжёлый для установщика. Нужна диаризация — запустите программу из
> исходников (см. ниже) и выполните `install-diarization.bat`.

Сборка происходит автоматически из этого репозитория (GitHub Actions,
`.github/workflows/build.yml`) — каждый пуш в `main` публикует новый релиз.

## Возможности

- **Источники**: ссылки YouTube и сотен других сайтов (через yt-dlp), локальные
  файлы MP4, MKV, AVI, MOV, WEBM, MP3, WAV, M4A и др. Поддерживается drag & drop.
- **Два движка** (переключение в Настройках):
  - **Локальный Whisper** (faster-whisper) — офлайн и бесплатно. Модели от `tiny`
    до `large-v3` (large-v3 — максимальная точность, уровень TurboScribe).
  - **Облачный API** — Groq (whisper-large-v3, быстрый и дешёвый) или OpenAI
    (whisper-1). Длинные записи автоматически режутся на части по паузам.
- **Диаризация** — разметка «кто из спикеров говорит» (pyannote 3.1, локально,
  работает с обоими движками).
- **Перевод**: встроенный перевод на английский прямо при распознавании (Whisper)
  и перевод готового транскрипта на любой язык через облачный API.
- **Экспорт**: TXT, субтитры SRT/VTT, DOCX, PDF (с кириллицей). Текст сегментов
  можно править прямо в программе перед экспортом.
- Очередь заданий, прогресс по этапам, отмена, тёмная тема.

## Быстрый старт (из исходников)

1. Установите [Python 3.10–3.12](https://www.python.org/downloads/)
   (при установке отметьте **Add python.exe to PATH**).
2. Двойной клик по **`run.bat`** — при первом запуске создастся окружение и
   установятся зависимости (несколько минут), затем откроется программа.

ffmpeg ставится автоматически (пакет imageio-ffmpeg) — ничего отдельно
скачивать не нужно.

### Первая транскрибация

1. Вставьте ссылку на видео и нажмите **Транскрибировать** — или перетащите файл в окно.
2. По умолчанию используется локальная модель `small`. Для максимальной точности
   откройте **Настройки** и выберите модель **large-v3** (скачается ~3 ГБ при первом
   использовании; на CPU работает медленно — см. «Скорость» ниже).
3. Готовый текст правится во вкладке «Сегменты», экспорт — кнопками внизу.

## Облачный режим (быстро на любом ПК)

1. Получите бесплатный ключ Groq: <https://console.groq.com/keys>
   (или ключ OpenAI: <https://platform.openai.com/api-keys>).
2. Настройки → «Облачный API» → вставьте ключ → Сохранить.

Groq использует ту же модель whisper-large-v3, работает очень быстро и имеет
щедрый бесплатный лимит.

## Определение спикеров (диаризация)

1. Запустите **`install-diarization.bat`** (скачает ~2 ГБ пакетов: torch, pyannote).
2. Создайте бесплатный токен: <https://huggingface.co/settings/tokens> (роль Read).
3. Примите условия моделей (кнопка «Agree and access repository»):
   - <https://huggingface.co/pyannote/speaker-diarization-3.1>
   - <https://huggingface.co/pyannote/segmentation-3.0>
4. Вставьте токен в Настройках и включите галочку **«Определять спикеров»**.

При первом запуске скачается модель (~1 ГБ), дальше — офлайн.

## Сборка VideoScribe.exe

Двойной клик по **`build.bat`** — соберётся папка `dist\VideoScribe` с
`VideoScribe.exe` (Python на компьютере пользователя не нужен).

Примечание: в exe не пакуется диаризация (torch слишком тяжёлый). Нужна
диаризация — используйте запуск из исходников (`run.bat`).

## Скорость и точность (локальный режим)

| Модель   | Размер  | Точность                     | Скорость на CPU*       |
|----------|---------|------------------------------|------------------------|
| tiny     | ~75 МБ  | низкая                       | очень быстро           |
| small    | ~460 МБ | хорошая                      | ~реальное время        |
| medium   | ~1.5 ГБ | высокая                      | в 2–3 раза медленнее   |
| large-v3 | ~3 ГБ   | максимальная (TurboScribe)   | в 4–8 раз медленнее    |

\* на современном 8-ядерном CPU; зависит от железа.

**Ускорение на видеокарте NVIDIA (опционально):** установите в окружение
библиотеки CUDA:

```
.venv\Scripts\activate
pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
```

и добавьте их папки `...\site-packages\nvidia\...\bin` в PATH (или скопируйте
DLL рядом с программой), затем в Настройках выберите устройство «GPU».
С GPU large-v3 работает в 5–20 раз быстрее реального времени.

## Частые вопросы

- **«Видео с возрастным ограничением»** — YouTube требует вход; такие ролики
  скачайте другим способом и откройте как файл.
- **Галлюцинации на тишине/музыке** — включён VAD-фильтр (Настройки), он
  решает большинство таких случаев.
- **Ключи хранятся** локально в `%APPDATA%\VideoScribe\config.json`.
- **Модели хранятся** в `%APPDATA%\VideoScribe\models`.

## Структура проекта

```
videoscribe/
├── main.py                  # точка входа
├── run.bat                  # запуск из исходников
├── build.bat                # сборка exe (PyInstaller)
├── install-diarization.bat  # доустановка диаризации
├── videoscribe.spec         # конфигурация PyInstaller
├── requirements.txt
├── requirements-diarization.txt
├── assets/fonts/            # шрифты для PDF
└── app/
    ├── config.py            # настройки
    ├── translate.py         # перевод через LLM
    ├── core/                # модели данных, ffmpeg, yt-dlp, нарезка,
    │                        # диаризация, пайплайн
    ├── engines/             # локальный faster-whisper и облачный API
    ├── exporters/           # TXT / SRT / VTT / DOCX / PDF
    └── gui/                 # PySide6: главное окно, настройки, потоки, тема
```
